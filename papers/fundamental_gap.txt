the fundamental gap of Sturm-Liouville operators on an inte rval, under the constraint

In [2], for the problem (2) with Dirichlet conditions, Ashba ugh and Benguria proved that
the optimal lower bound for Γ for symmetric single-well potentials is achieved if and onl y

Harrell were furthermore able to analyze the case where V = V0 +V1, where V0 is a

3.1. The class of single-well potentials and single-barrier den sities.
Deﬁnition 3.1. Let 1<M ≤ ∞. The function V is called a single-well function if V is
non-increasing on [0,a ] and non-decreasing on [a,π ], for some a ∈ [0,π ]. The point a is
called a transition point (with no assumption of uniqueness). The notation below will be
used through this article:
SW[0,π],M = {V (x) : 0 ≤V (x) ≤M, whereV is a single-well function on [0,π ]}.

density if w is non-decreasing on [0,b ] and non-increasing on [b,π ] for some b ∈ [0,π ].
