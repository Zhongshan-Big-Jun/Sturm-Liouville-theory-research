# 证书修订补记：隔离审查退回后的三项修正

本页接续 `certificate-repair.md`，后者和第一次回执均冻结保留。第一次隔离审查（包 `f979adc8…`）独立重算了全部 57 条事实，所得台账与当前台账逐字节一致，但整体判定为 CHANGES_REQUIRED。数学事实没有失败；下列测试与复用表述仍有缺陷，不能用该回执直接放行。

1. 原测试向接收器传入不支持的 `--ledger`，把参数解析失败误记成证书拒收。修后的测试对接收器使用位置参数，对表格程序使用其实际 `--ledger` 接口。先用同一调用函数验收有效台账，再验证故意失败、异常和不可判定三种生成结果：生成器分别退出 1/2/1；两个消费者均须退出 1，且错误明确包含 `last generation did not succeed`；接收器另须给出 JSON `REJECTED`。禁止把 argparse `usage:` 当作通过。旧成功台账和旧表格的字节必须保持。
2. 真曲线卡另一处仍把 55 条解析事实归于已退役的 Decimal 卡。该处改为当前有理包络入口；57 条台账合同和原非零阈值没有减少。旧 Decimal 卡及历史代码仍保留失效身份。
3. `Q=[1,2]×[.4,.5]` 是闭盒，原 `T1,T2` 是开区域。正确包含关系是 `Q°` 的相位像进入 `Ti`，闭盒像进入 `closure(Ti)`：相位在 Q 上连续，且内部点可逼近每个边界点。反例 `q=1,c=1/2` 给出 `alpha1=gamma=pi/3`，不满足 Ti 的严格 q、c 条件，现保留在正文和卡中。边界上的严格符号不由“严格不等式连续延拓”推出；J1 定理已有整个闭包上的统一下界 6499/7500，J2 定理已有整个闭盒 `[.655,1.0472]×[1,2]` 上的严格负号。原解析目标、阈值和结论均保留。

修后测试和运行日志位于 `certificate-checks-v2/`，最终证书复核回执另行绑定当前源文件。首次退回及其独立计算记录位于 `certificate-reviewer/` 与 `certificate-review-receipt.json`。本补记不将数值回归升级为一般解析证明，不表示新增 Lean 形式化，也不表示完整重审所有 O3a 推导。
