# 胞界合并构造

## 解析
构造周期延拓配置时, 相邻胞元的同值尾块与首块必须合并为一块. 对胞元 $[1,R,1]$ 的 $n$ 次周期重复, 合并后为 $2n+1$ 块模式 $[1,R,1,R,\dots,1]$: $n$ 个 $R$-块宽 $t/n$, 两个端 $1$-块宽 $st/n$, 内部 $n-1$ 个 $1$-块宽 $2st/n$. 未合并会在胞界 $1|1$ 处产生伪跳点, 导致错误结论.

## 适用范围
- 适用: 周期延拓构造的数值复现 ([[mw-periodic-extension]]); 任何胞元端点同值的周期结构.
- 边界情形: 合并后块数与跳点数变化; 需按新块序列重新赋权重.
- 不适用: 无 (纯数值工程规范).
