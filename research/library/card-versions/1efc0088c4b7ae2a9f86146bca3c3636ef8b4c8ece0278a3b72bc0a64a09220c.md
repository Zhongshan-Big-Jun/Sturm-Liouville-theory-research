# fp 臂最大根列追踪 (fp-arm-max-root)

## 解析
追踪零点集 $\{R_1(a,b,R)=0\}$ 的固定点分量 (fp-component S3):
固定 $a$, 求 $b$-方向的方程 $R_1(a,\cdot,R)=0$ 的根, 取每列最大根
(即最大 $b$) 作为分支点, 得到列 $(a_j,b_j)$. 具体做法: 对固定 $a$,
先在 $(s,b)$ 平面用 secular 方程求特征值 $s_1,s_2$ (对 $b$ 网格化),
再用 $R_1=\sin^2(s_1 a)/n_1-\sin^2(s_2 a)/n_2$ 求 $b$-根 (向量化).
沿 $a$ 递增时用隐函数斜率 $g_1'=-R_{1a}/R_{1b}$ 做 Newton 迭代加速 $b$.

## 适用范围与陷阱
- 适用: 近竖直分支 ($R\to 1^+$, $db/da$ 很大) 时 S3 的追踪;
  可确定分支端点 (a_min, a_max) 与 $b_{\rm top}$.
- 陷阱:
  - 逐 $a$ 列根时可能跳到其他分支, 需限制 $|b-b_{\rm prev}|$ 步长;
  - **伪根 (F-017)**: $R\le100$ 时在 $a=a_0$, max-root 列给出常数
    $b=0.41939681$ (R1=1.6e-4, off-branch); 真实唯一根是 $b=a_0$.
    计算 $h(a_0)=u(a_0)-b_0$ 时只用 $u$, 不受伪 $b(a_0)$ 影响;
  - 退化根: 空势垒 $b=a$ 恒在 $\{R_1=0\}$ 上, 须区分空势垒根与真实分支;
  - 大 $R$ 时 $a\gtrsim 1/2$ 处有片层跳跃 (tracew 数据被污染), 改用
    剖面追踪 (s33_profile.py) 得干净分支.
- 不适用: 作为严格证明手段; 只能产出数值证据, 分支存在性/唯一性须另行证明
  (隐函数定理 + R2 零点控制).

## 验证与备注
- e15_*.json (R=1.02..1e6) 全部由该法生成; $R$ 较小时首行有伪根 (F-017).
- 实例: R=1.05 时 S3 从 $(a_0,a_0)$ 爬升到 fp (0.420835,0.579165), 顶端
  (0.4258,0.877); R2 在片层上恰在 fp 处为零 (网格精度内).
- 脚本: R-20260807T163000Z-c1center-9C4E2A/reproducibility/e15_authoritative.py
  (max_root_col), s33_profile.py (剖面式干净 S3), s33_r1plus.py.
