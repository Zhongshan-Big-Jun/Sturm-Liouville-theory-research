# 第十轮审计：反例与验证说明

## 一、全区间世俗函数的无极点分解

设左半区间的物理传递矩阵为 M=[[a,b],[c,d]]，行列式为1。反射后的右半区间传递矩阵为 [[d,b],[c,a]]；因此全区间矩阵的01元为2bd。对半区间块宽1/50、12/25与密度10000、1，初始状态(0,1)给出 b=O(ω)/ω、d=E(ω)，即报告中的 F=2EO/ω。

E=0 给半区间 Dirichlet–Neumann 模态，可偶延拓；O=0 给半区间 Dirichlet–Dirichlet 模态，可奇延拓。两者不能在同一正频率同时为零，因为传递矩阵可逆。函数连续，四个互不相交区间的端点异号分别证明存在四个不同全区间特征值。

## 二、精确有理包络不是高精度浮点替代

对有理 x，取正弦／余弦的80阶 Taylor 多项式 P80（零系数也属于该阶数），由 Lagrange 余项

    |sin(x)-P80,sin(x)| <= |x|^81 / 81!
    |cos(x)-P80,cos(x)| <= |x|^81 / 81!

得到精确有理上下界。所有加减乘和区间端点比较均用 `fractions.Fraction`。无需先有 π 的浮点或区间近似。

`root_bracket_certificates.json` 存储每个括区的函数值包络，分别包含理想有理块宽与输入浮点数的精确二进制有理块宽。四组包络各自严格异号。它们负责根存在性的解析证书；`roots_of` 返回的浮点值与残差只是计算错误的实际复現输出。

网格示例的端点也转成精确二进制有理数再计算 E·O 的符号。因ω>0，2/ω不改变符号，因而证明该格两端的全区间函数同号。程序跳过这一格，不能用后续二分恢复其中的根。

本轮没有将上述四个括区直接视为完整的前四根枚举证书。四个更低的不同根存在，本身已经足以否定程序首项的“第一根”身份。

## 三、根位置与根序号应有分开的验证

任何高精度 Newton／secant 细化都可以从第五根附近初值收敛到极精确的第五根。残差小、根为正、列表有序、返回数量充分，都不能证明这是完整的低频列表。

修复路线是以 Sturm/Prüfer 计数约束序号，再作局部位置求解。若最终要给区间证书，还须对计数、相位提升和每个括区使用可靠包含估计。本审计给出的是故障定位与必要修复条件，没有将某个未经实现和验证的求根器作为替换交付。

## 四、反射扇区的正确代数

Jd=(d_{2n},...,d_1)。接口的几何反射是 R(x)=1-Jx，因此线性作用为-J。

- P_preserve=(I-J)/2，对应 Jd=-d，沿 x0+td 仍镜像成对。
- P_break=(I+J)/2，对应 Jd=d，反射将扰动参数t变成-t。

二者互补、正交且幂等。代码 `a[reversed_indices]=-a` 是可逆映射−J，不是其中任何一个投影：它保留全部维数，不能把随机向量限制到半维扇区。

若需要纯扇区实验，可以使用上述投影，零向量时重采样，再在可行小步长内检查最终接口。源程序已有的 `sym` 拼接方式属于第一类，应保留。

## 五、新构造的有限精确检查承担什么

Legendre 提升和边界矩阵、M_c²多项式、Γ3矩阵、等差积分恒等式等，均由 Sympy 在精确表达式下核对。有限 n 的端点和带宽检查不证明所有 n 的结论；全指标结论由报告所列原文中的反复积分、正交性和范数估计承担。

移动接口校准独立使用一个单接口的显式世俗函数

    F(ω,a) = [3 sin(ω(2-a)) + sin(ω(3a-2))] / (4ω),

在 a=1/2 处以隐式求导比较 λ_a、λ_aa。它是70位数值交叉检查，不是对任意接口配置的统一二阶定理证明，也不替代正文的弱方程／材料导数论证。
