# 第十六轮：反例、积分公式与有界密度方向的谱尾界

基线：`ec45bf99ae746b0a3699557e06700a3c00c5a831`。

## R16-01：Taylor 区间分区在进入有理算术前已经变成浮点

位置：`misc/rigid1d.py::der_sign2`、`der_sign_adaptive`。这不是 I/D2 的多项式链式法则错误，而是 a、b、span、中心、半宽和最终修正混用了 Python float。

### 整数端点也能触发

令 ε=2^(-62)，

\[
f(x)=\frac{x-x^2/2}{15}-\epsilon x,\quad 0\le x\le1.
\]

f'(x)=(1-x)/15-ε，因而在 (1-15ε,1] 为负。以下调用实际返回 `(True,3)`：

```python
fn=lambda z:(z-z*z/2)/15-Fraction(1,2**62)*z
der_sign2(fn,0,1,True,base_n=3,max_n=3)
```

尽管端点 0、1 是整数，`w=span/(2*n)` 已经生成浮点数 1/6。最后一格的中心为精确 5/6，fc.d1.lo=1/90-ε，M=1/15。源码的 `M*w` 是浮点数，随后 `Fraction-float` 继续进入浮点运算，给出正下界约 1.734723475976807e-18。真正的同一 Taylor 下界是 -ε。

改成 Fraction(0)、Fraction(1) 后，原函数拒绝该声明；诚实的正性样例 f=x+x² 仍通过。

### 相邻浮点端点还会错误缩小覆盖区间

令 a=1.0，b=nextafter(1.0,2.0)=1+2^-52，t=1+3·2^-54，f(x)=tx-x²/2。f'(b)=-2^-54。原两个验证器却分别返回 `(True,1)`。

原因是 `(a+b)/2` 舍入成 1，而 `(b-a)/2=2^-53`。重新拼出的 c±w 在浮点运算下并未覆盖原区间右端 b。整个负导数部分可以在进入 I 之前就被遗漏。

**修复条件：**在所有端点运算之前统一精确化或明确拒绝不支持的输入类型；整数端点也不能走 Python 普通除法。检查顺序、计数和宽度参数，所有修正界保持有理数。不得把“输入是浮点”理解成只需检验有限浮点格点；这里的命题是实区间上的符号。

**影响边界：**活动 `misc/e1_certgen.py::_taylor` 已经在第一行将 a、b、Target 转为 Fraction，并使用独立的精确分区；没有调用这两个分区助手。因此该反例不推翻当前 57 项 E1 证书。本轮没有重跑该完整生成器。

## R16-02：可算的缩放方向暴露高频配对混叠

取单位区间 ρ≡2，h≡2。|t|<1/2 时 ρ_t=2(1+t) 仍在 [1,4] 的盒内。精确谱、归一化模态及其方向配对为

\[
\lambda_k(t)=\frac{k^2\pi^2}{2(1+t)},\quad u_k(x)=\sin(k\pi x),
\quad C_{kl}=\int_0^1h u_ku_l=\delta_{kl}.
\]

因此对所有 n 和任何覆盖 n,n+1 的截断 N，

\[
Q=\tfrac12D_n''(0)=D_n(0)=\frac{(2n+1)\pi^2}{2}.
\]

所有尾部配对精确为零；这里不存在需要等待 N→∞ 消除的谱尾误差。

实际执行 `SpectralProbe([(1.,2.)], Modes=61, Order=64)` 及 `q_formula`，n=60 时 Q≈1468.8578582412，而真值≈597.1110662659。n=20、Order=32 时甚至得到 Q≈-1667.4793719377，而真值≈202.3268902223。

默认 64 点配对矩阵的 max|C-I|≈0.392656，第60行的平方和≈2.029327；而精确 Parseval 总预算为1。使用同一组正确根，改为闭式三角积分，误差消失到本次浮点对照尺度。

同一个常密度分为两个相同块时，Q改善为597.1110453835，但未达到初试设定的2e-7绝对误差目标；初试失败保留在 results/initial_failed.*。四个相同块或单块128点达到原误差目标，未把两块结果改记为通过该目标。

**准确归因：**这反驳的是未分辨求积输出可以直接当作目标配对/符号的做法，不反驳谱二阶变分公式。源码明确把结果限定为有限数值证据，未宣称严格区间认证；仍有必要分别记录求积误差和谱截断误差，而不是只打印一个模式数和 Q。

### 分块常数方向的精确积分公式

在一个长度 L 的共同密度/方向块中，以中点为原点写

\[
u_i(\xi)=c_i\cos(\omega_i\xi)+d_i\sin(\omega_i\xi),\quad
c_i=u_i(0),\quad d_i=u_i'(0)/\omega_i.
\]

对该块常数方向 H，

\[
\int_{-L/2}^{L/2}H u_iu_j\,d\xi
=\frac{HL}{2}\left[
(c_ic_j+d_id_j)\operatorname{sinc}\frac{(\omega_i-\omega_j)L}{2}
+(c_ic_j-d_id_j)\operatorname{sinc}\frac{(\omega_i+\omega_j)L}{2}
\right],
\]

此处 sinc(z)=sin(z)/z、sinc(0)=1，不是 NumPy 的 π 归一化版本。混合的奇函数积分为零，所以公式也适用于 i=j。公共分块必须包含密度与方向的全部真实断点。

这给出解析上无求积混叠的有限配对。浮点实现仍须处理小相位、近频率的消去，以及质量归一化；测试里的 `analytic_pairings` 仅用于中等相位参考，不是一个已经解决任意极端输入的生产级实现。

## R16-03：窄格中的节点折叠把方向质量丢掉

取 ρ≡1，δ=2^-50，几何块长

\[
(1/2,\delta,1/2-\delta),
\qquad h_\delta=\delta^{-1}\mathbf1_{(1/2,1/2+\delta)}.
\]

全部块长正且接口在 binary64 中互异。精确 ∫hδ=1，且第一归一化模态 u1=√2sin(πx) 满足

\[
\int h_\delta u_1^2
=1+\frac{\sin(2\pi\delta)}{2\pi\delta}
\ge2-\frac{(2\pi\delta)^2}{6}>1.99999999999999999999999999999.
\]

最后一界可用 π<22/7 作完全有理比较，本轮检查没有将高精度浮点值当作证明。

源码的64个格内节点只有9个不同坐标，10个舍入到右端点，被 `block_direction` 的 `searchsorted(...,side='right')` 归到下一块。实际 ∑w h≈0.9390022688，第一配对≈1.8780045377。

增加到128点仍只有9个不同坐标，20个落到右端点，配对≈1.8799479141。把δ增为2^-40则是通过的正对照。因此这里首先是坐标与断点归属错误，不是普通高频积分混叠。

`checked_bump_breaks` 已对P3专用脉冲检查实际节点分辨率，但普通 `quadrature_rule` / `SpectralProbe.pairings` 没有同样的守卫。应将约束贯彻到普通入口，或对已知分块方向改用局部坐标和解析积分；分辨不了时明确失败。不能通过更改数学容许类、默默扩大块宽、再增加节点数来掩盖问题。

## C16-TAIL：有界真实密度方向的可核验谱尾估计

这是可加入修复的解析补充，不是声称当前所有浮点输入已经成为区间证书。

取有界正密度 0<m≤ρ≤M，实有界方向 h。模态满足 ∫ρu_k²=1。记

\[
c_{kl}=\int h u_ku_l,\quad
J_k=\int\frac{h^2}{\rho}u_k^2,
\quad E_{k,N}=J_k-\sum_{l=1}^N|c_{kl}|^2\quad(N\ge k).
\]

在加权 L2(ρ) 中，将 (h/ρ)u_k 作正交展开，由 Parseval 得

\[
E_{k,N}=\sum_{l>N}|c_{kl}|^2\ge0.
\tag{T1}
\]

因此

\[
0\le\sum_{l>N}\frac{|c_{kl}|^2}{\lambda_l-\lambda_k}
\le\frac{E_{k,N}}{\lambda_{N+1}-\lambda_k}.
\tag{T2}
\]

设 a=λn、b=λn+1，N≥n+1，Q_N 为精确前 N 项公式，则

\[
-\frac{b^2E_{n+1,N}}{\lambda_{N+1}-b}
\le Q-Q_N\le
\frac{a^2E_{n,N}}{\lambda_{N+1}-a}.
\tag{T3}
\]

证明只需把两条非负谱尾带入 Q 的两个符号。也可以使用更粗的 E_(k,N)≤||h/ρ||∞²。在长度L上，λ_(N+1)≥(N+1)²π²/(ML²)，当这个比较下界大于b时可替代分母中的λ_(N+1)，无需另解一个特征值。

**可算锐性检验。** ρ=2、h=2cos(πx)、n≥2、N=n+1 时，c_(k,l)=1/2仅在l=k±1；低模态无尾，上模态只遗漏n+2。所以E_n=0、E_(n+1)=1/4，(T3)左界恰好取到。本轮以符号恒等式核对。

**实施边界。** J_k、c_kl、特征值和Q_N必须由可靠区间或解析值支持，才能据(T3)认证符号；不能把有误的浮点配对塞进公式并把负的E擅自截成零。普通 h∈L∞ 的(T1)不能直接作用于δ或δ′接口方向，也不给出脉冲宽度趋零时的一致界，不解决ND/G1或一般接口Hessian的定号。
