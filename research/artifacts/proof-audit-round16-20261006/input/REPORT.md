## 2. R16-01：表面上是精确有理验证，分区却先进入了float

来源：`misc/rigid1d.py` 的 `der_sign2`、`der_sign_adaptive`；完整数学与可运行反例见 `analytic_notes.md`。

令 ε=2^-62，f=(x-x²/2)/15-εx，区间为[0,1]。真实 f'(1)=-ε，且末端一个非空区间内均为负。但

```python
der_sign2(fn,0,1,True,base_n=3,max_n=3)
```

返回 `(True,3)`。整数端点不能避免错误，因为 Python 的 `/` 先将半宽变成float；最后一格中的 `Fraction - float` 又变成浮点，真实的负下界 -ε被报告为正的约1.7347e-18。

另外，a=1.0、b=nextafter(1.0,2.0)、f(x)=(1+3·2^-54)x-x²/2 时，两个验证器均返回 `(True,1)`，但右端导数为 -2^-54。此时舍入中心与半宽重构的区间漏掉了原来的右端。

同一数学区间用Fraction输入后原函数拒绝错误声明；诚实正性样例仍通过。修复应在任何算术前规范化端点、宽度和计数，不是最后再向外移动几位小数。

**没有误伤活动证书：** `misc/e1_certgen.py::_taylor` 第一行已有 `a,b,Target=F(a),F(b),F(Target)`，自身分区保持有理数，没有使用这两个助手。本项针对仍在公共有理模块中导出的另两个验证入口；本轮没有运行活动57条证书的完整生成。

## 3. R16-02：正确的谱和归一化，仍可被欠分辨积分变成错误Q

来源：`scripts/_gapn2_second_variation_probe.py::quadrature_rule`、`SpectralProbe.pairings`、`q_formula`。

取单位区间ρ=2，方向h=2；|t|<1/2时仍在盒[1,4]内。λ_k(t)=k²π²/[2(1+t)]，u_k=sin(kπx)，方向配对C_kl=δ_kl。因此Q=D''/2=(2n+1)π²/2；任何覆盖目标模态的谱截断都已经精确，所有尾配对为零。

实际61模态的结果：

| 每块Gauss点数 | n | 源码Q | 精确Q |
|---:|---:|---:|---:|
| 32 | 20 | -1667.4793719377 | 202.3268902223 |
| 64 | 20 | 179.8309027782 | 202.3268902223 |
| 64 | 60 | 1468.8578582412 | 597.1110662659 |
| 128 | 60 | 597.1110662658 | 597.1110662659 |

64点时max|C-I|≈0.392656，第60行平方和≈2.029327，已经超过精确Parseval预算1；同一配置n=2的对照仍很准确。说明不能只靠少数低模态回归发现问题。

保留同一组根，改用三角恒等式积分后结果恢复，错误由求积而非根编号产生。同一常密度仅改变“人为分成几块”的表示也会显著改变原求积输出。

**接收边界：**原代码明确声明有限数值证据，本轮没有把它说成伪造严格区间证书。新增问题是分辨率不足时仍返回并用于比较的配对/符号，且没有区分谱截断误差与求积误差。对于分块常数方向，可使用附录的闭式积分；对一般回调必须显式说明分辨率、误差与未决状态，不能声称有限采样可认证任意黑箱有界函数。

## 4. R16-03：节点位置本身不可分辨，增加阶数也无法恢复质量

取ρ=1，δ=2^-50，块长(1/2,δ,1/2-δ)，h=δ^-1·1_(1/2,1/2+δ)。块长正且全体端点在double中互异。

64节点中只有9个不同点，其中10个舍入到右端，随后由全局 `searchsorted(...,side='right')` 分配到下一块。源码积分方向质量约0.9390022688，而真值严格是1；第一模态配对约1.8780045377，而有理比较证明真值比2小不到10^-29。

128节点时仍只有9个不同点，配对约1.8799479141。δ=2^-40是可分辨、通过的正对照。这里不是R16-02的高频问题，而是局部坐标/单点断点归属的问题。

P3专用 `checked_bump_breaks` 已检查实际节点。普通积分路径也应有检查或结构化的解析积分；无法分辨时明确拒绝，不能默默改几何，也不能只提高Order。

## 5. 两项可以直接吸收的建设性结果

### 5.1 有界方向的谱尾界

附录C16-TAIL证明，对实际加权归一化模态和有界实方向h，

E_(k,N)=∫(h²/ρ)u_k²−Σ_(l≤N)|∫h u_ku_l|²≥0。

若N≥n+1、a=λ_n、b=λ_(n+1)，则

\[
-\frac{b^2E_{n+1,N}}{\lambda_{N+1}-b}
\le Q-Q_N\le
\frac{a^2E_{n,N}}{\lambda_{N+1}-a}.
\]

可用Sturm比较下界替代λ_(N+1)，也可用||h/ρ||∞²替代未知剩余能量作粗界。ρ=2、h=2cosπx、N=n+1提供左界取等的可算模型。

这能使“有限谱截断”具有明确数学误差边界，但要据此认证仍需有限配对和谱参数的可靠包络。负的浮点E是数据不可信的信号，不能随手截成零后宣称尾部消失。它不是δ型接口Hessian的尾部证书。

### 5.2 任意整数阶的稳定多项式替代系

当前A10的活动范围只到s=2、4。新稿 `proofs/integer_left_definite_riesz_systems.md` 给出每个固定整数r≥1的完整构造。

在真实域V_r中，取所有阶数小于r的偶阶端点导数为自由数据；奇阶数据由Krein条件给定。唯一的次数≤2r−1的Hermite多项式提升这些数据。低提升数为d_r=2ceil(r/2)，所以偶数阶为r列，奇数阶为r+1列。

减去低提升以后，余项在H0^r中。用b_n^(r)=J^r e_n、n≥r展开，其r阶导数形成Legendre正交系。由真实整数域的双向Sobolev范数估计，得到固定r,c、独立于次数N的Riesz上下界。新稿给出可显式计算的常数、精确有限多项式张成、带宽|n-l|≤2r及系数尾误差。

三阶低提升可选1,x,(1−x²)²/8,x(1−x²)²/8，再加J³e_n、n≥3。

独立复核通过后，可把A10的整数阶构造部分从2/4推进到所有非负整数；不关闭非整数稳定基、c↓0一致性、原稀疏族稳定坐标、一般约束或ND/G1/M3/KP。本结果不依赖第十五轮尚未合并的任意删项扩展。
