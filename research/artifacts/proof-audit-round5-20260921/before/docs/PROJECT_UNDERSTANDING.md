## 目前怎样理解这个项目

一条主线通过矩递推和增长条件理解正交系及稠密性. 另一条主线通过变分结构, 开关位置和相位约束理解谱极值. 两条主线都需要识别哪些中间表示保留了原问题的全部约束. 这是从现有路线提炼的研究观察, 不是关于全部 Sturm-Liouville 问题的新定理.

目前最有帮助的两类变化是:

- 从公式正确转向检查对象是否正确. [幂域障碍](../tools/krein-power-domain-polynomial-obstruction.md) 说明代数多项式逆与满足 Krein 边界条件的真正算子逆有不同的适用范围. 新传输构造可以先检查边界条件与算子域, 再讨论完备性.
- 从单个符号不等式转向利用完整可行域. KP-DET 的相位, 质量与分支条件共同限制可行 tuple. [sequence-26][kp-whiteboard] 保存了精确约化及尚未闭合的局部缺口; 丢掉约束后的反例不能直接反驳完整问题.

## 2026-09-20 审计带来的范围修正

[修订报告](../reports/proof-audit-20260920/REPORT.md) 给出两项可复用的教训. 同一稀疏族的 H3 稠密性可以通过谱截断向低阶传递, 不能越过幂域成员性向任意高阶推广; 第二轮谱系数给出更精确的边界: p4 仅在 s<7/2 的非负幂域中, 3<s<7/2 的同族稠密性仍待研究. 完整谱系必须保留常数和 x 两个低模态. 精确有理数程序则必须先证明超越函数包络的方向, 再检查有理数链; 两个相同分数比较成功不证明包络成立. 本轮以 C10 修复 C1, 以归一化对象修复证书接口, 保留已有原始证明包供追溯.

## 怎样留下可继续使用的理解

沿用 [tools/](../tools/) 的卡片与索引. 一个有用的记录可以是定理, 变换, 构造, 程序, 失败路线或尚待检验的直觉. 写清真正用到的假设, 可复核的来源位置, 能帮助哪个问题, 以及什么新信息会改变判断. 文字格式可以自由, 证据状态必须明确.

文献卡应指向实际读取的版本及定理号, 页码或段落. agent 的批注与人的批注都可保留, 并区分原文内容, 自己的推导和未证解释. 索引或插件生成的指针表负责找到卡片; 自由批注不应被索引重建覆盖. 具体读取, 批注与恢复命令跟随 [研究插件](https://github.com/xsoc1/rigorous-open-math-research) 当前版本文档, 本仓库不复制另一套实现.

较长研究的恢复入口沿用 [state/RESUME.md](../state/RESUME.md) 及对应 run 的白板. 它们含历史段落, 当前 KP-DET 的最后已核对位置见 [sequence-26][kp-whiteboard]. 插件可以帮助记录下一动作, 在途任务与证据位置; 已有被哈希绑定的 checkpoint 保持原样. 本页没有创建另一份 checkpoint 或重新启动研究任务.

## 第二轮审计形成的工作理解 (2026-09-20)

候选值的达到性、全局界与谱指标传递需要各自的证明义务. 新的首对变分证明先取得极值,
再由零能量与界面匹配确定平衡配置, 最后计算闭式. 另一方面, 全序列比值下确界为 1
可以由常密度序列直接看出; 库内“已经解决”与旧综述“开放”的矛盾说明, 状态指针也必须检查.

形式化反馈应在域成员性、边界接口、符号、量词与归一化这些关键位置介入.
盲回译只看实际声明, 隐含类型不明确就留下缺口. 每次修订后的验收使用新的隔离会话,
作者自己的成功计算不自动成为独立认可. 纠错保留旧字节及失败原因, 同时切断其默认复用.
具体证据与仍未形式化的部分见 [第二轮报告](../reports/proof-audit-round2-20260920/REPORT.md).


## 第三轮审计形成的工作理解 (2026-09-20)

一般递推中的正反馈项可以比乘积下界大得多. A=3,B=2 时系数差的超额为零, 实际解却是 2^m-1. 因此增长下界、增长上界与精确模型各有不同的假设; 正式工具卡应保留这个反例, 以便后续迁移时先检验缺失项.

基扰动会同时改变两个递推系数, 也可能离开算子域. “最终足够小”不能自动替代全指标条件: 有限前缀可能消去增长分量. 本轮构造的 P2 正交元说明有界且趋零的扰动仍可能使形式像族不完备.

商空间论证必须计算真实商映射下的像, 并核对被消去的全部模态. 正定形式范数中的谱截断经连续商映射传递稠密性, 修复了直接使用原始特征函数正交条件的漏洞. 这些经验及局部形式化的实际范围见 [第三轮报告](../reports/proof-audit-round3-20260920/REPORT.md).

## 第四轮审计形成的工作理解 (2026-09-21)

商类的极限不能自动还原成选定函数代表的极限. 本次 n=2,3 的差落在 span{1,x}, 因而商范数看不见, 普通 H1 却能测到. 新推导需把代表选择、归一化和商映射分别写明.

递推问题的变量选择可直接改变证明难度: 阶乘缩放把这组具体三阶方程化为二阶差分的一阶方程, 从同一结构得到有限重构、正项尾级数和有理比值分类. 这一结构只覆盖明确的 P,Q,R, 不能据此推广到任意系数族.

一项有理函数可以有不同的未约分参数表示, 还可能只在尾部有定义. 分母消失、约分后的极点和全局归一化须分别核对. 精确代码也要在混合输入类型时维持精确除法, 并以错误样本真正触发非零退出码. 详见 [第四轮报告](../reports/proof-audit-round4-20260921/REPORT.md).
