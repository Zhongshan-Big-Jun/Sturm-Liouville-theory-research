## 4. C15-A11-SCALE：全部成员窗口内的任意删项

完整新证明在 `proofs/full_window_deletions_and_finite_constraints.md`。它以 A1 成员窗口、真实平方域及 A12 余有限分类为明确输入；不把这些输入全部描述成本轮重证。

任意 `N subset {0,1,4,5,...}`，定义奇偶保留集 Se、So。固定 c>0，0<=s<7/2。若两支倒数和都发散，闭包恰为遗漏且连续的中心迹核交；需要关注的原族指标为：

| s | I(s) |
|---|---|
| `[0,1/2]` | 空集 |
| `(1/2,3/2]` | 0 |
| `(3/2,5/2]` | 0,1 |
| `(5/2,7/2)` | 0,1,4 |

对应迹是 f(0)、f'(0)、f''(0)。任一支倒数和收敛则闭包无限余维。于是任意保留集在全空间稠密，当且仅当两支倒数和发散并保留 I(s)。

新增充分性连接是：用 p4、p5 修正第二组边界残差，证明满足首组边界的普通 H4 空间有界包含于每个目标 Hc^s；再构造满足边界条件的 Hc^s 值全纯族

```
P_e(z,x)=|x|^(z+6)-(z+6)/(z+4)*|x|^(z+4),
P_o(z,x)=x*P_e(z,x),  Re z>0.
```

其目标范数至多四次增长。连续复线性零化泛函作用后除以 `(z+1)^4`，给有界解析函数。发散保留集产生违反 Blaschke 条件的零点列，因此它消去全部高尾；问题归约到 A12 的一个余有限集。没有把二阶稠密性直接插值到高阶。

必要性改在普通 L2 中对原列构造无限维零化泛函，再连续限制到目标幂域，不错误地使用二阶 Kc 逆来传输不同阶数的障碍。

三个临界值1/2、3/2、5/2由 A12 的准确边界保留。s>=7/2、c=0、统一常数、收敛侧全空间表示与稳定逼近不在结论中。

## 5. C15-A3-KREIN：有限余维连续约束的逐项筛选

设 V 是 Hc^s 中有限个连续复线性泛函的共同核，NV是单个原族成员实际属于V的指标。新证明推出：

```
closure(span{p_n : p_n in V}) = V
iff V is an intersection of a subset of the continuous central trace kernels.
```

因此四段阶数上这样的不同子空间恰有1、2、4、8个。依据是有限余维排除了某一支倒数和收敛；两支发散后由上一定理得到坐标迹核交。反向直接检查低列迹值，再用 A12。

这是实际 Krein 幂域中 A3 的一个完整子类，不是任意非对角 Hilbert 空间 O1' 可表示性理论。不适用于允许重组的 `span{p_n} intersect V` 或投影族，也不覆盖无限个约束。
