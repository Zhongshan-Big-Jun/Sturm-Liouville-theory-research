# R15-01：尚未统一的旧扫描后端

基线 `ec45bf99ae746b0a3699557e06700a3c00c5a831`。

## 1. 活动关联与限定

`op03_gap_fixed.py::lams_precise` 仍被 `op03_gap_fh.py` 实际导入。`scripts/README.md` 仍将后者列作第七轮诊断入口，并解释了其相对于旧 precise 传播顺序的修复。这里检查的是这个尚未接入统一相位枚举的后端，不是 `_sl_prufer.indexed_roots` 回归。

没有声称固定 R4 的既有 FH 表一定算错。本轮 R4 三块正对照的前 3 根与统一引擎相符。反例说明这个函数不能继续作为对任意合法正块密度返回“前 k 根”的可靠复用入口。

## 2. 反例

理论权在单位区间上为：端部两个长度 L=21/1000 的块密度 10000，中部长度 479/500 密度 1。源码输入为相应 binary64 数；精确符号检查同时覆盖理想有理长度和实际二进制有理长度。

当前源函数要求 k=3 时返回频率：

```
3.26579575077895...
6.51585909...
6.73158888...
```

第一项是实际的第五模态。独立 65 位物理传递、逐块求积归一化和三角解零点计数得到前五频率约为：

```
0.7462197727914001176782337853117935
0.7604843852750858667850982642803124
2.2352811194758186926536829414125834
2.2465634455691712422536143272866242
3.2657957507789527458356847755313506
```

内部零点分别为 0,1,2,3,4。高精度数字不是区间认证；下节给出前四个根的精确有理括区。

单用 Rayleigh 比较已经足以排除首项身份：理想单位区间权满足 rho≥1，故 ω1≤π<22/7；源首项却大于 22/7。对实际二进制长度，总长偏差在浮点量级，同一比较 ω1≤π/总长仍严格小于首项。

k=1 时源首项改成 2.235281...；k=6 时源首项又是 0.746219...。增加 k 不保持前缀。tol、smax_scale 两个形式参数在函数体中未用于控制对应行为，不能靠调它们获得可靠枚举。

## 3. 精确括区

在左半区间，置 θ=100Lω，φ=Cω，其中理想 C=479/1000，实际输入 C 为中块二进制长度的一半。两个匹配函数为

\[
E=\cos\theta\cos\varphi-\frac1{100}\sin\theta\sin\varphi,
\quad O=\frac1{100}\sin\theta\cos\varphi+\cos\theta\sin\varphi.
\]

全区间 Dirichlet 世俗函数 F=2EO/ω。E=0 对应中心 Neumann，O=0 对应中心 Dirichlet；镜像延拓给全区间本征函数。

以下四个互不相交有理区间的相应端点严格异号：

| 分支 | 左界 | 右界 |
|---|---:|---:|
| E | 0.746219772791 | 0.746219772792 |
| O | 0.760484385275 | 0.760484385276 |
| E | 2.235281119475 | 2.235281119476 |
| O | 2.246563445569 | 2.246563445570 |

`checks.py` 的 `sincos` 用 Fraction 与 32 项 Taylor 和，以及全部阶导数绝对值≤1 的 Lagrange 余项。未使用浮点真值作符号依据。结果 JSON 保存全部精确有理端点像。

旧函数的搜索上界为 π sqrt(rho_max)(k+2)+20，网格固定 30000 点。在 k=3 的实际网格中，前一对和后一对根各处于单个格内，两个端点不变号而被跳过。二分 90 次不能找回未被选中的根格。

## 4. 最小收口方案

活动 `lams_precise` 应委托同一个按模态编号的 DD 引擎，明确返回的是频率而非特征值；不再维护另一个固定网格。所有保留调用者核对单位、数量、编号及异常规则。对旧 tol/smax_scale 给出真实兼容/弃用策略，不能暗中接受但不生效。

保留冻结历史版本、旧扫描和回执；新的可复用入口及导航与活动调用实际一致。不要求修改无关联的全部历史副本，也不把本例扩大成当前 G2、A11 或默认 R4 FH 公式的反例。
