# 整数阶 Riesz 替代坐标
固定 c>0 与每个非负整数 r, 在实际复幂域中重建边界相容的 Hermite-Legendre 坐标. 奇数阶的低提升数为 r+1; 常数对次数一致, 对 c 和 r 可依赖. s=0 独立采用标准 Legendre 基. 原稀疏族删除 p6 仍稠密, 所以非零逐项缩放与重排不能把原族变成 Schauder/Riesz 基. 这是不同对象的替代, 非整数和 c趋零一致性未完成.
