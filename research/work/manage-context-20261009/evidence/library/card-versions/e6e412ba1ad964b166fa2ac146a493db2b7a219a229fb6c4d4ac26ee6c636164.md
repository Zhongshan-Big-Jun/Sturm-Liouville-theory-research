# 定义先于名称
空间是实际自伴正 Krein 算子的复幂域. 不能把普通 Sobolev 空间、实积分模型或有限维多项式子空间直接当作同一目标. 原族成员窗口为 0<=s<7/2; 它不是整个算子幂域存在的范围限制.
