# Plugin performance evaluation: A6 rational product solutions

This directory contains the first controlled A/B performance experiment using
an unsolved problem from the Sturm-Liouville research project.

- Problem: see `PROBLEM-A6-RATIONAL.md`
- Baseline run: `R-20260822T000000Z-a6-baseline`
- Reuse-gate run: `R-20260822T000000Z-a6-reuse`

Metrics are collected from the subagent session logs and from the
`performance_log.md` files written by each agent.
