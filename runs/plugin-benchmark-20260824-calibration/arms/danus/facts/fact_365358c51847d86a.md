# F9: Q_n has exactly n roots in (delta,1), all simple

## STATEMENT
For each integer k=1,...,n there is exactly one theta_k in (0,pi) with Phi(theta_k)=k pi. These are precisely the zeros of Q_n on x in (delta,1); each is simple. Hence Q_n has exactly n simple zeros in (delta,1).

## PROOF / JUSTIFICATION
By F8, on x in (delta,1) (where theta=arccos P(x) runs strictly from pi down to 0 as x increases from delta to 1), Q_n=0 iff sin Phi(theta)=0 iff Phi(theta)=k pi for an integer k. Since Phi is strictly increasing from 0 to (n+1)pi, the values k=1,...,n occur exactly once each; k=0 and k=n+1 are endpoints not in (0,pi). At a zero, derivative of the sine factor is |z| cos Phi * Phi', with |z|>0, cos(k pi)=(-1)^k !=0 and Phi'>0, hence the zero is simple. The map theta |-> x=sqrt((2 cos theta -2 + alpha)/alpha) is one-to-one from (0,pi) to (delta,1); its inverse has derivative d(theta)/dx = -alpha x / sin theta, nonzero on (delta,1), so simplicity is preserved in x.
