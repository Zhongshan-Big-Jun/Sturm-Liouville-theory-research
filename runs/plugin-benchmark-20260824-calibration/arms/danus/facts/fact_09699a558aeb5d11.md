# F2: A=E*S has determinant 1 and trace 2P

## STATEMENT
Let A=E S. With c=cos y, q=sin y, s>1, alpha=s+2+s^{-1}, r=s^{-1},
A = [[c^2 - s q^2, (1+r) c q], [-(1+s) c q, c^2 - r q^2]],
det A=1, tr A = 2c^2 - (s+r) q^2 = 2 - alpha q^2.
Set P = (tr A)/2 = c^2 - (s+r)q^2/2.

## PROOF / JUSTIFICATION
Compute E S by matrix multiplication: (E S)_{11}=c*c + q*(-s q)=c^2 - s q^2; (E S)_{12}=c*(q/s)+q*c=(1+1/s)cq=(1+r)cq; (E S)_{21}=(-q)c + c*(-s q)=-(1+s)cq; (E S)_{22}=(-q)(q/s)+c*c=c^2-r q^2. Then det = (c^2 - s q^2)(c^2 - r q^2) + (1+s)(1+r)c^2 q^2. Using r=1/s, (1+s)(1+r)=s+2+r = alpha. This simplifies to (c^2+q^2)^2=1. Trace as stated. Also alpha = s+2+s^{-1} > 4 for s>1.
