# F1: Matrix identities for E, S, C_s

## STATEMENT
For s>1, y in R, set c=cos y, q=sin y, E=[[c,q],[-q,c]], S=[[c,q/s],[-s*q,c]].
Then C_s(y)=S(y)E(y), det(C_s)=det(E)=det(S)=1, and
C_s(y)=[[c^2 - s^{-1}q^2, (1+s^{-1})cq], [-(1+s)cq, c^2 - s q^2]].

## PROOF / JUSTIFICATION
Direct multiplication: S*E = [[c^2 - q^2/s, cq + cq/s],[-s c q - c q, -s q^2 + c^2]] = [[*, (1+1/s)cq],[-(1+s)cq, c^2 - s q^2]] as claimed. Determinants: det E = c^2+q^2=1; det S = c^2+q^2=1; det C_s = det S det E = 1. This matches the definition of C_s in the frozen task.
