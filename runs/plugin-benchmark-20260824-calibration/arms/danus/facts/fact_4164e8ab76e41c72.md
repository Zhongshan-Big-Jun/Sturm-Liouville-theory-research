# F7: No roots in the hyperbolic region 0<|x|<delta

## STATEMENT
Let alpha=s+2+s^{-1}>4 and delta = sqrt((alpha-4)/alpha) in (0,1). Then delta is the unique x>0 with P(x)=-1. For every x with 0<|x|<delta, Q_n(x) != 0. Also Q_n(delta) != 0.

## PROOF / JUSTIFICATION
Since P is even and increasing on (0,1), P(x)<-1 exactly when 0<x<delta. Put P=-cosh v, v>0. Standard hyperbolic form: U_k(P)=(-1)^k sinh((k+1)v)/sinh v. Therefore
Q_n(x)=(-1)^n/sinh v [sinh((n+1)v) - r sinh(nv)], r=1/s.
Because n+1>n and sinh is strictly increasing on (0,infty), sinh((n+1)v)>sinh(nv)>r sinh(nv) for 0<r<1. The bracket is strictly positive, so Q_n != 0. At P=-1 we use U_k(-1)=(-1)^k(k+1). Then
Q_n(delta)=(-1)^n[(n+1)-n r], which is nonzero because n+1 - n r >= n+1 - n > 0.
