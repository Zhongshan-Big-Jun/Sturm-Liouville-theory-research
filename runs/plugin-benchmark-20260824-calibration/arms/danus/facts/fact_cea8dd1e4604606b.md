# F4: Entry (AE)_12 and the key algebraic substitution

## STATEMENT
Let x=cos y, q=sin y, alpha=s+2+s^{-1}, r=s^{-1}, P=(tr A)/2 = 1 - alpha/2 + alpha x^2/2.
Then
(AE)_{12} = q(alpha x^2 - s), and alpha x^2 - s = 2P + r.

## PROOF / JUSTIFICATION
Direct multiplication:
(AE)_{12} = (c^2 - s q^2)q + ((1+r)cq)c = q(c^2 - s q^2 + (1+r)c^2)
= q((2+r)c^2 - s q^2)
= q((2+r)c^2 - s(1-c^2))
= q((2+r+s)c^2 - s) = q(alpha c^2 - s) = q(alpha x^2 - s).
For the second identity: 2P = 2(1-alpha/2+alpha x^2/2) = 2-alpha + alpha x^2, so 2P+r = alpha x^2 + (2-alpha+r) = alpha x^2 - s, because alpha=s+2+r.
