# Toy Examples

n=1, s>1:
  Q_{1,s}(x) = ((s+1)^2/s) x^2 - s.
  Explicit roots: x = +/- s/(s+1), both in (-1,1).

n=2, s=2:
  A = 9/2, B = 5/2, z = (9x^2 - 5)/4.
  Q = U_2(z) + (1/2)U_1(z) = 4z^2 + z - 1.
  Four roots in (-1,1) (numerically ~ +/-0.408, +/-0.830).

Boundary R=1 (s=1):
  z = 2x^2 - 1 and Q = U_n(z) + U_{n-1}(z). Same 2n count:
  n=1 roots +/-1/2; n=2 roots about +/-0.309, +/-0.809.
