# Counterexamples / Failure probes

- No counterexample found for the stated claim.
- The analogous Chebyshev combination U_n(z) + a U_{n-1}(z) does NOT have n roots
  in (-1,1) for every a>0.  For a=5 and n=1 it has no root in (-1,1);
  for a>1 some roots leave (-1,1).  This is why the hypothesis 0<a<=1
  (equivalently R>=1) is essential.
- z< -1 interval is a possible false-root zone, but for a=1/s<1 the combination
  is sign-definite there; for a>1 it is not.
