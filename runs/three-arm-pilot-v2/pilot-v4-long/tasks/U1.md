# U1: Batchelor-scale liminf

Consider the advection-diffusion equation on `T^2 = [-pi,pi]^2`:

    d_t rho + U(t,y) d_x rho = Delta rho.

Assume `0 != rho(0,.) in L^2_{x,y}` is mean-zero and `||U||_{L^infty_t L^2_y} < infinity`.
Prove that for the weak solution `rho`,

    liminf_{t -> infinity} ||rho(t)||_{dot H^{-1}} / ||rho(t)||_{L^2} > 0.

State external theorems with exact hypotheses; numerical evidence is not a proof.
