# Plan History

Curated record of abandoned / revised decomposition plans. The **regulator** is the only agent permitted to append to this file, and it does so when its decision is REVISE_PLAN or REWRITE. The **decomposer** must read this file before producing a new plan.

Format: each entry is a level-2 section identifying the attempt / revision, the strategy in one sentence, the key step statements verbatim, the regulator's diagnosis of why the plan failed, what NOT to try again, and what (if anything) might still be reused.

If a decomposer truly needs the full prior YAML, it can read it directly at `decomposition/attempt_*/revision_*/decomposition.yaml`.
