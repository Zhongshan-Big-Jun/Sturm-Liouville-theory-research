## 目前怎样理解这个项目

一条主线通过矩递推和增长条件理解正交系及稠密性. 另一条主线通过变分结构, 开关位置和相位约束理解谱极值. 两条主线都需要识别哪些中间表示保留了原问题的全部约束. 这是从现有路线提炼的研究观察, 不是关于全部 Sturm-Liouville 问题的新定理.

目前最有帮助的两类变化是:

- 从公式正确转向检查对象是否正确. [幂域障碍](../tools/krein-power-domain-polynomial-obstruction.md) 说明代数多项式逆与满足 Krein 边界条件的真正算子逆有不同的适用范围. 新传输构造可以先检查边界条件与算子域, 再讨论完备性.
- 从单个符号不等式转向利用完整可行域. KP-DET 的相位, 质量与分支条件共同限制可行 tuple. [sequence-26][kp-whiteboard] 保存了精确约化及尚未闭合的局部缺口; 丢掉约束后的反例不能直接反驳完整问题.

## 成功与失败路线留下了什么

| [旧级联路线](../tools/largeR-level-cascade.md), [旧 log 猜想](../tools/m3-log-correction.md) | 头部已标 SUPERSEDED. 旧正文中的 STRICT/OPEN 描述属于历史, 不能重新当作有效前提 | 有新的独立残差表达式或尺度假设时, 可以检验曾用方法的适用条件, 不把旧标签当永久禁令 |
| KP-DET 的 quotient-only 路线 | 商的单调性本身不足以排除同号 Jacobi 核. 原 run 保存了还需要的约束与精确身份式 | 获得质量方程, 端点比值或可行域符号的额外信息后, 重新评估组合方法 |
| KP-DET 的 mass-defective witness | 放宽质量约束能产生坏符号配置. 它限定了某类简化方法的适用范围 | 新论证证明放宽条件与完整条件之间的桥接, 或明确只研究放宽后的问题时 |
| [Q9 三份 benchmark 证明][q9] | 外审通过的三条路线给出不同的必要界和正性区域, 可比较其实际使用的假设 | 先核对题面和参数字典. 若复用更强中间命题, 单独核对其定义域; 暂未接入本项目 canonical |
| Route 11 的 NO_RETURN | 两项任务没有有效工件; 一个遭遇额度限制, 另一个原因未知 | 恢复时先核对已有工件与任务状态. 无返回不构成数学失败证据 |

## 下一步有价值的研究动作

1. 对齐 Q9 的三份外部证明与本地 P20-P21, 确认完整题面和所有参数对应关系, 再讨论 canonical 接收及它对 KP-DET 的实际影响.
2. 比较 Q9 路线中更强的中间结论, 检查能否提炼成可复用的相位不等式或精确证书程序. 先在新的相关问题上检验, 再称为通用工具.
3. 对不同文档中的 G2 按定义, 参数范围与依赖逐项对齐. 旧名称相同不保证陈述等价; 本轮没有解决这一状态冲突.
4. 在一般 O1'/O1'LD 或新的边界条件问题上, 检查矩工具能够迁移的部分与失效的位置. 用后续研究的实际复用结果评价工具库的价值.

这些是可调整的候选动作. 人可以改变优先级, 提出反例方向或否定某个解释; 不需要先填完一套流程表.

## 怎样留下可继续使用的理解

沿用 [tools/](../tools/) 的卡片与索引. 一个有用的记录可以是定理, 变换, 构造, 程序, 失败路线或尚待检验的直觉. 写清真正用到的假设, 可复核的来源位置, 能帮助哪个问题, 以及什么新信息会改变判断. 文字格式可以自由, 证据状态必须明确.

文献卡应指向实际读取的版本及定理号, 页码或段落. agent 的批注与人的批注都可保留, 并区分原文内容, 自己的推导和未证解释. 索引或插件生成的指针表负责找到卡片; 自由批注不应被索引重建覆盖. 具体读取, 批注与恢复命令跟随 [研究插件](https://github.com/xsoc1/rigorous-open-math-research) 当前版本文档, 本仓库不复制另一套实现.

较长研究的恢复入口沿用 [state/RESUME.md](../state/RESUME.md) 及对应 run 的白板. 它们含历史段落, 当前 KP-DET 的最后已核对位置见 [sequence-26][kp-whiteboard]. 插件可以帮助记录下一动作, 在途任务与证据位置; 已有被哈希绑定的 checkpoint 保持原样. 本页没有创建另一份 checkpoint 或重新启动研究任务.
