## 目前怎样理解这个项目

一条主线通过矩递推和增长条件理解正交系及稠密性. 另一条主线通过变分结构, 开关位置和相位约束理解谱极值. 两条主线都需要识别哪些中间表示保留了原问题的全部约束. 这是从现有路线提炼的研究观察, 不是关于全部 Sturm-Liouville 问题的新定理.

目前最有帮助的两类变化是:

- 从公式正确转向检查对象是否正确. [幂域障碍](../tools/krein-power-domain-polynomial-obstruction.md) 说明代数多项式逆与满足 Krein 边界条件的真正算子逆有不同的适用范围. 新传输构造可以先检查边界条件与算子域, 再讨论完备性.
- 从单个符号不等式转向利用完整可行域. KP-DET 的相位, 质量与分支条件共同限制可行 tuple. [sequence-26][kp-whiteboard] 保存了精确约化及尚未闭合的局部缺口; 丢掉约束后的反例不能直接反驳完整问题.

## 怎样留下可继续使用的理解

沿用 [tools/](../tools/) 的卡片与索引. 一个有用的记录可以是定理, 变换, 构造, 程序, 失败路线或尚待检验的直觉. 写清真正用到的假设, 可复核的来源位置, 能帮助哪个问题, 以及什么新信息会改变判断. 文字格式可以自由, 证据状态必须明确.

文献卡应指向实际读取的版本及定理号, 页码或段落. agent 的批注与人的批注都可保留, 并区分原文内容, 自己的推导和未证解释. 索引或插件生成的指针表负责找到卡片; 自由批注不应被索引重建覆盖. 具体读取, 批注与恢复命令跟随 [研究插件](https://github.com/xsoc1/rigorous-open-math-research) 当前版本文档, 本仓库不复制另一套实现.

较长研究的恢复入口沿用 [state/RESUME.md](../state/RESUME.md) 及对应 run 的白板. 它们含历史段落, 当前 KP-DET 的最后已核对位置见 [sequence-26][kp-whiteboard]. 插件可以帮助记录下一动作, 在途任务与证据位置; 已有被哈希绑定的 checkpoint 保持原样. 本页没有创建另一份 checkpoint 或重新启动研究任务.

## 第三轮审计形成的工作理解 (2026-09-20)

一般递推中的正反馈项可以比乘积下界大得多. A=3,B=2 时系数差的超额为零, 实际解却是 2^m-1. 因此增长下界、增长上界与精确模型各有不同的假设; 正式工具卡应保留这个反例, 以便后续迁移时先检验缺失项.

基扰动会同时改变两个递推系数, 也可能离开算子域. “最终足够小”不能自动替代全指标条件: 有限前缀可能消去增长分量. 本轮构造的 P2 正交元说明有界且趋零的扰动仍可能使形式像族不完备.

商空间论证必须计算真实商映射下的像, 并核对被消去的全部模态. 正定形式范数中的谱截断经连续商映射传递稠密性, 修复了直接使用原始特征函数正交条件的漏洞. 这些经验及局部形式化的实际范围见 [第三轮报告](../reports/proof-audit-round3-20260920/REPORT.md).

## 第四轮审计形成的工作理解 (2026-09-21)

商类的极限不能自动还原成选定函数代表的极限. 本次 n=2,3 的差落在 span{1,x}, 因而商范数看不见, 普通 H1 却能测到. 新推导需把代表选择、归一化和商映射分别写明.

递推问题的变量选择可直接改变证明难度: 阶乘缩放把这组具体三阶方程化为二阶差分的一阶方程, 从同一结构得到有限重构、正项尾级数和有理比值分类. 这一结构只覆盖明确的 P,Q,R, 不能据此推广到任意系数族.

一项有理函数可以有不同的未约分参数表示, 还可能只在尾部有定义. 分母消失、约分后的极点和全局归一化须分别核对. 精确代码也要在混合输入类型时维持精确除法, 并以错误样本真正触发非零退出码. 详见 [第四轮报告](../reports/proof-audit-round4-20260921/REPORT.md).


## 第五轮审计形成的工作理解 (2026-09-21)

尾部递推与完整初值问题承载的信息不同. 本轮显式Green函数说明, L2中确实存在满足高阶尾部递推的非零衰减矩; 它们对应零点的值迹与导数迹. 缺少对p0或p1的正交条件时, 不能继续以“排除所有可实现最小矩”为目标. [第五轮报告](../reports/proof-audit-round5-20260921/REPORT.md)记录原候选反证及已独立审查通过的替代分类.

单项式的有限删除稠密性不能沿形式表达直接转交给算子像族. 在具体算子域上, 应先找连续泛函的对偶代表, 再检查被保留的多项式是否检测到全部这些方向. 对当前s=2问题, 这把余有限子类转成二维迹空间问题, 并解释为何斜约束f(0)=f'(0)会保留1+x却失去两个单独低阶项.

还需区分“人为选出的指标集”和“由闭空间实际保留的指标集”. 前者可以有限地删去任意高阶项而不改变本轮闭包; 后者一旦余有限, 闭性和完整尾部逼近就强迫所有n>=4的p_n都在V中, 实际只能缺p0、p1. 这为后续受约束空间检索提供了一个可直接使用的排除条件.

下一步候选问题 (未证): 在其它图范数或边界条件下, 有限删项的缺陷是否仍可由有限个连续内部迹刻画? 必须重新核对迹的连续性、尾部的代数结构和截断逼近, 不能把本轮s=2结果直接推广到s=3或一般非余有限子族.


## 第六轮审计形成的工作理解 (2026-09-21)

代数缺少有限个方向, 与在给定拓扑下是否稠密, 是两件需要分别证明的事. 连续满射能够传递已知密度; 由整个多项式空间稠密, 不能直接推出稀疏族的投影稠密. 对M=closure_H span{p_n}, 准确条件是V intersect M^perp={0}; M=H是保证它的一种充分条件.

有限矩检验应放在尾部正交障碍上. 在全部多项式已稠密嵌入H的契约下, 完整三角尾部把障碍维数压到有限, 再由实际低位保留项检验其共同核; 这给出非空且可复用的准则. 在整个无限维V上要求有限测试单射, 反而使前提没有实例. 后续工具卡应先验证假设能否同时满足, 并明确有限矩是否由空间中的实际向量实现.

幂域成员性也不应只逐个筛选名字. p4与p6各自出Hc4, 组合p6-(7/2)p4却能抵消残差. 四迹映射的固定右逆因此成为构造稠密多项式图核心的工具, 补齐了0<=s<7/2. 这一成功路线提示后续边界问题可先研究有限维残差及相消结构, 再研究闭包; 迁移到新算子仍是待验证想法. [第六轮报告](../reports/proof-audit-round6-20260921/REPORT.md)保存证明、反例及独立审查范围.


## 第七轮: 统一估计、接口坐标与薄重块

分块方程的统一性不应依赖每一块都有正宽度. 跳点处二阶导数一般跳跃, 但全区间Volterra积分式仍成立. 由密度的统一上下界控制射击解, 再用权归一化传递端点斜率间隙, 可以跨越趋零首块而保留一致端点负性. 与内区间C1根隔离结合, 才能把隐函数定理的局部解提升为整个升序区域的弱反差唯一解.

导数必须连同参数空间一起记录. 单接口坐标与左右镜像反向移动的独立坐标相差两项贡献, 驻点方程却可能完全相同. 因此检验梯度系数要选非驻点, 并用独立差分和正确的权归一化对照. 普通L2的势扰动与变权弦的广义特征问题也采用不同分母.

一般n的上确界极限不需要先求出每个有限R的最优接口. n个等距薄重块产生n维低能平台空间, 使lambda_n趋零; 在n个中心取零的余维n空间提供lambda_(n+1)的反向下界. 两侧min-max夹逼得到(n+1)²pi². 其可迁移的思路是同时控制“有限个低模态”和“去除这些自由度后的分段谱障碍”. 对图、非等长分区或带质量约束的迁移仍是待验证想法, 不能据此宣称已获相应新定理.

[第七轮修订报告](../reports/proof-audit-round7-20260921/REPORT.md)记录证明、非驻点回归和隔离审查. 第六轮0<=s<7/2及投影修复保持原字节; canonical图本轮未接收新节点.
