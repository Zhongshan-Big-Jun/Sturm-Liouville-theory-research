# EvE 双种群进化 (Evolutionary Ensemble of Agents)

## 解析

EvE 把现有 coding agent 包成去中心化进化集成, 两个种群共进化:
- **求解器种群**: 仓库内功能组件 (代码/证明草稿) 的变异体.
- **agent 种群**: 指导与技能的自我精化.
- 每个变异由**测试或评分**驱动 (shell 脚本, agent judge prompt, 或组合), 边际收益决定取舍; 不需要任务特定工作流或手工技能.
- 适用条件: 结果可测试或可评分.

关键启发: 把"改进"建模为可评分变异 - 每次变异必须能被客观判据 (测试/评分/证据等级) 接受或拒绝, 进化方向由边际收益决定.

## 适用范围

- 适用: 结果可判定或可评分的任务 (算法设计, 代码改进, 数学问题求解, 证据等级提升).
- 边界: 需要评分函数; 评分不可靠时进化方向会漂移.
- 不适用: 主观/开放结局任务; 本项目当前不运行 EvE 全流程 (成本高), 只采纳其思想.

## 采纳建议

- 工具库演化: 新方法条目 = 变异, 采纳判据 = 是否解决已知阻塞/是否提升证据等级/是否节省检索成本; 在 tools/README 维护日志记录每次"变异"的边际收益.
- 研究选题: 对开放问题清单按证据状态评分 (已证/部分/数值/开放), 自动生成"提升一个等级"的候选子问题 (与提出问题功能面联动).
