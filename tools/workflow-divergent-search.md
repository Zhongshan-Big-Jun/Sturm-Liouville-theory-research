# 发散式检索契约 (Divergent Searcher Contract)

## 解析

把文献检索设计为**发散角色**: 目标是广度 - 找到有趣结果并提取, 而不是决定什么可用.
与审计分离: 检索者只做轻审计 (结果是什么, 谁的, 哪来的, 是否大致相关);
正确性审计 (陈述是否成立, 前置条件是否满足, 是否独立于目标) 交给独立验证者.
硬约束是**来源诚实**: 每条记录必须可追溯到真实查询结果或论文笔记, 禁止编造结果/陈述/定位器/引用.

分层检索流水线 (每层记录贡献):
1. 从陈述/义务/阻塞点提取关键词, 构建**关键词族** (同义词, 符号变体, 旧词汇), 逐族搜索后合并.
2. 先查知识库 (KB), 复用已有卡片, 不重复追溯.
3. 扫本地 references 与最近查询索引.
4. 精确陈述用 Matlas; 综述/相关工作/定理溯源用 arXiv.
5. 通用网页 (教材, 讲义, 课程页, 博客, MathOverflow/MSE, 期刊页, GitHub) - 非论文来源常含构造, 反例, 数值证据; 这类发现是合法结果, 如实记录来源.
6. 深读命中正文 (不停在摘要), 提取需要的陈述 + 前置条件 + 定位器.

## 适用范围

- 适用: 任何"找定理/找文献/找反例来源"的检索子任务; 检索候选多且质量参差时.
- 边界: 检索者不裁决, 只传递; 宁可多传候选给审计层, 不预先丢弃.
- 不适用: 需要即时裁决的场景 (检索者不替代验证者).

## 采纳建议

- 写入 rigorous-open-math-research 的文献检索子任务: 检索产出格式固定为 查询 -> 结果 -> 定位器 三要素, 无法追溯的一律不写 (与项目规则"引用必须附链接, 不得编造文献"一致).
- 相关性判断与正确性审计分离: 检索阶段不裁决, 研究/验证阶段裁决.
- 检索先查 tools/ 与 research_cache/, 再 arXiv/OpenAlex/zbMATH, 再通用网页; 每层记录贡献, 防止重复追溯.
