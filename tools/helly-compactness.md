# Helly 紧性与极值存在性

## 解析
单调有界函数族存在逐点收敛子列 (Helly 选择定理). 对单调函数类 (如分布函数, 有界变差函数), 保证极值问题的存在性: 目标泛函 (特征值) 在子列极限处连续, 因此 $\inf$ 或 $\sup$ 被达到.

## 适用范围
- 适用: 单调/有界变差类中的极值存在性; 为 [[bang-bang]] 与 [[keller-variational]] 提供存在性基础.
- 边界情形: 只给存在性, 不给结构; 子列极限可能不是处处连续的阶梯 (需要额外结构定理).
- 不适用: 非单调类 (需其他紧性, 如 $L^p$ 弱紧, 见 [[mde-extremal]]).

## 验证与备注
- Keller 1976 Section 2 用该类紧性证明 $\mu(a)$ 可达.
